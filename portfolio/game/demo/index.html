Playable build. For What Lies Beneath, exported from Godot 4.6.3 on 2026-06-12 and served as plain files - no server, no cross-origin isolation headers. The export is single-threaded with no GDExtension, so it needs neither SharedArrayBuffer nor COOP/COEP and runs on any static host. Click the canvas first, then: Enter confirms, WASD or arrows move the cursor, Esc backs out. The path is faction select, then the march map, then a battle. Two known gaps in this export: it predates the current tip by about ten weeks, and the music directory was not packed, so it runs silent.
